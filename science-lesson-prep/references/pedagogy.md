# 教学设计与写作要求

本文件规定备课材料的内容结构与表达方式。写 Markdown 之前先读一遍。

> 本文件里的示例以数学为主，但框架（学情分析、教学目标、重难点、教学过程、
> 板书、作业、反思）对物理、化学、生物同样适用。写非数学科目时请同时阅读
> `subjects.md`——那里列了各科特有的写法与环节差异。

## 一、语言要求

用教师写教案的语言，不用商业文案的语言。

| 不用 | 用 |
| --- | --- |
| 亮点、价值、赋能、成果、项目 | 教学重点、教学难点、教学环节 |
| 打造、助力、抓手、闭环 | 引导、探究、归纳、巩固 |
| 让学生获得……能力 | 通过……活动，使学生…… |

句式参考：

- 引导学生观察……，归纳出……
- 通过小组讨论，让学生自己发现……
- 教师追问：……？学生回答后，教师板书……

## 二、教案（kind = jiaoan）必备板块

按以下顺序组织，`##` 为板块标题：

1. **学情分析** —— 学生已有基础、可能遇到的困难、本课的生长点
2. **教学目标** —— 分知识与技能、过程与方法、情感态度与价值观三层
3. **教学重难点** —— 明确写出重点是什么、难点是什么、难点为何难
4. **教学过程** —— 按环节展开（见下）
5. **板书设计** —— 用表格呈现黑板分区
6. **课后作业** —— 分层布置，含基础题与思考题
7. **教学反思** —— 留出填写空间，可列出反思角度

### 教学过程的写法

每个环节用 `###` 标题，建议 4~6 个环节：

```markdown
### 环节一　复习引入
提问：……？
引导学生……
$$（本环节的关键公式）$$
```

环节内部要写出**师生活动**，不只是知识点罗列。例如：

- 教师提问……，学生独立思考后同桌交流；
- 请两名学生板演，其余学生在学案上完成；
- 教师巡视，收集典型错误，投影讲评。

### 教学目标示例

```markdown
- 知识与技能：理解二次函数 $y = ax^2 + bx + c$ 的图象是一条抛物线，能通过配方把它化为顶点式 $y = a(x-h)^2 + k$，并说出顶点坐标与对称轴。
- 过程与方法：经历"列表—描点—连线—归纳"的作图过程，通过对比不同参数取值下的图象，体会数形结合与从特殊到一般的思想方法。
- 情感态度与价值观：在动手作图与小组交流中感受数学的对称美，增强主动探究的意识。
```

## 三、导学案（kind = xuean）

导学案面向学生，与教案的关键差别：

- **隐去教师的设计意图**，只保留学生的任务与问题；
- **强化填空与留白**，关键结论让学生自己写出来；
- **留出演算空间**，用 `::: blank 4` 插入空行；
- 结构通常为：学习目标 → 知识回顾 → 探究任务 → 例题演练 → 当堂检测 → 课堂小结

写法示例：

```markdown
### 探究一　把一般式化为顶点式

填空：

$$y = ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + \frac{4ac-b^2}{4a}$$

顶点坐标是（　　，　　），对称轴是直线　　　　　。

::: blank 3
```

## 四、课件（kind = kejian）

课件面向课堂演示，与教案的关键差别：

- **每页信息量要少**：一页一个要点，正文不超过 6 行；
- `##` 标题即每页标题，`###` 渲染为页内小标题；
- **结论性内容用列表或表格呈现**，不要整段文字；
- 图象单独成页或与要点并排；
- 顺序通常为：封面 → 复习引入 → 探究 → 例题 → 练习 → 小结 → 作业

反面示例（一页塞太多）：

```markdown
## 二次函数的性质
二次函数的一般式是 y = ax² + bx + c，其中 a、b、c 是常数且 a ≠ 0。
当 a > 0 时开口向上，当 a < 0 时开口向下。对称轴是 x = -b/(2a)，
顶点坐标是 (-b/(2a), (4ac-b²)/(4a))。判别式 Δ = b² - 4ac 决定抛物线与 x 轴的交点个数……
```

正确做法是拆成多页，每页只讲一件事。

## 五、同源异构

同一节课同时产出教案与课件时，**必须先完成一份完整教学设计，再分别改写**，
不能各写各的。三份材料必须保持以下内容一致：

- 课题与课时定位
- 核心知识点与符号定义
- 探究情境与典型例题（数据、条件、结论都要一致）
- 课后作业与评价维度

差异只在呈现方式：

| 材料 | 侧重 | 差异做法 |
| --- | --- | --- |
| 教师教案 | 教学设计与教学逻辑 | 写出师生活动、设计意图、学情应对预案 |
| 学生导学案 | 认知探究与思维留白 | 隐去意图，改写成任务与填空，留出书写空间 |
| 教学课件 | 视听直观与课堂交互 | 压缩文字，突出结论卡片、图象、例题分步 |

## 六、内容自检

生成后除了跑 `qa_check.py`，还要自查：

- 学情分析是否针对本课具体内容，而不是套话；
- 教学目标是否可观察、可评价（"理解""掌握"后面要有具体行为）；
- 例题的解答过程是否完整，关键步骤有没有跳步；
- 教案、学案、课件的例题数据是否完全一致；
- 课后作业是否与本节课的重难点对应。

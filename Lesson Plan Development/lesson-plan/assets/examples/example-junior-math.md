# 《勾股定理》教案（第 1 课时）

## 教材分析

本课是第 17 章的起始课，承接前面学过的"直角三角形两锐角互余"和"三角形三边关系"，
把对直角三角形的认识从**角的关系**推进到**边的关系**，是学生第一次遇到"用面积关系
证明长度关系"的方法。它为下一课时的逆定理提供直接基础，也为后面学习锐角三角函数、
两点间距离公式埋下"数形结合"的第一块基石。因此本课的重点不只是记住结论，
更要让学生经历"从面积到边长"的发现过程。

> 【设计说明】教材分析写成三句话：在本单元的位置、与前后内容的逻辑关系、本课要留下的东西。
> 这里特意点出"用面积证明长度"这个方法，是因为它是本章后面反复使用的工具，
> 而不是一个一次性的技巧。写教材分析时要问自己：这节课真正留下的、以后还要用的东西是什么？

## 学情分析

- **已有基础**：学生已掌握直角三角形两锐角互余、三角形三边关系，能进行简单的面积计算。
  课前测显示：45 人中 41 人能正确计算正方形面积，32 人能完成简单的割补（把不规则图形
  补成长方形后求面积）。
- **前概念／迷思**：多数学生认为直角三角形三边之间**没有定量关系**，只知道角的关系；
  约一半学生听说过"勾三股四弦五"，但把它当作"3、4、5 这一组数的巧合"，
  不认为它是普遍规律。
- **学习障碍**：从"面积关系"到"边长关系"需要一次抽象跳跃——学生习惯算长度，
  不习惯用面积表示长度的平方；另外，以斜边为边的正方形在网格上无法直接数格子，
  割补是空间操作上的障碍。这两个障碍必须分开处理，不能同时出现。

> 【设计说明】学情分析写到"多少人有""错在哪""为什么错"这个粒度，教学决策才能落地。
> 最后一句是关键：把两个障碍分开，直接决定了下面环节二（先排除操作障碍）
> 和环节三（再处理割补）的先后顺序。学情分析不是写给检查看的，是用来决定教学顺序的。

## 教学目标

- **T1（知识与技能）**：能准确说出勾股定理的内容，并写出符号语言
  （在 Rt△ABC 中，∠C = 90°，则 $a^2 + b^2 = c^2$）；能由直角三角形中已知的两边求出第三边，
  当堂练习 2 题全对。
- **T2（过程与方法）**：能通过数格子和割补法计算以直角三角形三边为边长的正方形面积，
  从三组数据中归纳出三边关系，并能说出"为什么正方形的面积等于边长的平方"。
- **T3（情感态度·素养）**：在小组用不同方法（数格子、割补、测量）验证同一结论的过程中，
  能向同伴说明自己的方法，并能对不同方法的适用范围作出判断
  （如"等腰直角三角形可以直接数格子，一般情况要割补"）。

> 【设计说明】三条目标各有分工：T1 是知识底线（带可测标准"2 题全对"）；
> T2 是过程，写到"能说出为什么面积等于边长的平方"，这是把抽象的一跃落到了行为上；
> T3 没有写"培养合作精神"这种空话，而是挂在"上台示范 + 判断方法适用范围"这个具体活动上。
> 注意 T2 和 T3 都可以在课堂上观察到，不是靠课后作业检验的。

## 教学重点与难点

- **教学重点**：勾股定理的内容，以及用"面积法"发现定理的过程。
- **教学难点**：从面积关系 $S_1 + S_2 = S_3$ 抽象出边长关系 $a^2 + b^2 = c^2$。
- **为什么难**：学生习惯直接计算长度，不习惯把"面积"和"长度的平方"看成同一个数。
  他们能在图形上看出"两个小正方形加起来等于大正方形"，但要把这一步翻译成
  "两条直角边的平方和等于斜边的平方"，需要一次符号化的抽象。
- **突破策略**：①先走等腰直角三角形这一特殊情形，此时斜边正方形可以直接数格子，
  排除割补的操作干扰，让学生只关注面积关系；②在记录单上把"面积"和"边长"两栏
  并排放在同一行，让 9 与 3、16 与 4、25 与 5 在视觉上直接对应，
  再追问"9 和 3 是什么关系"，把"面积=边长的平方"这一步由学生自己说出来。

> 【设计说明】难点必须写到"卡在哪 + 为什么卡 + 怎么破"三件事。
> 突破策略的第②条是本课最关键的设计——不靠讲解，而是靠**记录单的排版**让抽象自然发生。
> 好教案的巧劲常常就藏在这种地方：不是教师多说一句，而是材料本身在引导思维。
> 写难点时如果只能写出"多加练习""反复强调"，说明难点还没想清楚。

## 教学思路

- **整体构想（设计理念）**：
  本节课以"探寻直角三角形三边定量关系"为核心议题，摒弃直接告知公式再机械套题的传统模式，设计"特例直觉（等腰直角） ──► 割补攻坚（一般直角） ──► 归纳猜想（面积关系） ──► 符号抽象（边长关系） ──► 验证应用"的问题链主线。通过两栏并排记录单与网格图景，帮助学生跨越从"几何直观面积"到"代数符号平方"的关键思维台阶，切实发展学生的几何直观、推理能力与抽象能力。

- **主线架构图（核心问题链）**：

```
主问题：直角三角形的三边长度之间，究竟存在怎样的定量规律？
  │
  ├─ 子问题 1（特例直觉）：在等腰直角三角形网格中，以三边为边长的正方形面积有何关系？
  │    └── 驱动动作：数格子直观感知 ──► 发现 S₁ + S₂ = S₃（指向 T2）
  │
  ├─ 子问题 2（操作攻坚）：当斜边正方形在网格中倾斜、无法直接数格子时，如何求其面积？
  │    └── 驱动动作：动手割补（出入相补） ──► 确认一般直角三角形仍满足面积和关系（指向 T2/T3）
  │
  ├─ 子问题 3（符号抽象）：面积关系 S₁ + S₂ = S₃ 究竟揭示了三边长 a, b, c 之间怎样的等式？
  │    └── 驱动动作：对比表格中面积与边长数据 ──► 提炼 $a^2 + b^2 = c^2$（指向 T1）
  │
  └─ 子问题 4（应用拓展）：如果已知任意两边长，能否求出第三边？在应用时必须守住什么前提？
       └── 驱动动作：变式计算与易错辨析 ──► 强化直角与斜边条件（指向 T1）
```

- **难点攻坚路线图**：
  `算术算边长思维（难以联想到面积） ──► 网格正方形面积拼图支架 ──► 记录单面积与边长并列排版 ──► 顿悟 $S=a^2$ ──► 完成 $a^2+b^2=c^2$ 抽象建构`

> 【设计说明】教学思路板块是全案的战略中枢。初中数学若无宏观问题链架构，教学过程就极易沦为零散提问。这里通过 1 个主问题统领 4 个递进子问题，使每个环节的教学意图均能回扣到这一思维路线上。

## 教学准备

- **教师准备**：3×3 与 5×5 网格纸各 45 张；预印《探究记录单》45 份（含三组数据表格，
  面积栏与边长栏并排）；预印"直角边为 3、4 的直角三角形三边正方形图"（斜边正方形
  画在网格上）45 份；勾股定理发现过程的课件（含割补法动画，仅在学生示范后再放）；
  磁性黑板贴片用于板书。
- **学生准备**：直尺、铅笔、剪刀；预习课本第 22–24 页。

> 【设计说明】教学准备写"多少份、什么格式"，不写"准备多媒体课件"。
> 记录单的格式是设计的一部分（见突破策略②），所以必须提前印好，不能课堂上临时画。

## 教学过程

### 环节一：情境导入（4 分钟）

- **教师活动**：出示一张房屋人字形屋架的图片，指出其中的直角三角形。提问："我们已经
  知道直角三角形两个锐角互余，也知道三边满足两边之和大于第三边。除了这两条，
  三条边之间还有别的关系吗？"在学生举例"勾三股四弦五"时追问："那 3、4、5 是碰巧，
  还是所有直角三角形都这样？"
- **学生活动**：独立思考 30 秒后与同桌交流；有学生会举出"勾三股四弦五"或生活中的
  直角三角板。
- **设计意图**：对应 T1 的起点。用"已知的角关系和三边不等关系不足以回答"制造认知冲突，
  引出本课的主问题——**直角三角形的三边之间到底有什么数量关系？** 追问"是碰巧还是规律"，
  是为了把学生的注意力从"记一个特例"转向"找普遍规律"。
- **评价点**：对应 T2 的起点。观察是否有学生主动提出"勾三股四弦五"，并留意他能否说出
  "这只是一组特例"。能把"特例"和"规律"分开，是本课思维的关键一步。

> 【设计说明】导入只给 4 分钟。导入的作用是提出主问题，不是铺垫知识。
> 注意导入里没有出现"$3^2+4^2=5^2$"——这个结论要由学生在环节四自己发现，
> 现在说出来就把探究的价值提前消耗掉了。

### 环节二：特殊情况探究——等腰直角三角形（8 分钟）

- **教师活动**：发下 3×3 网格纸（每格边长 1）。提出任务："在网格上画直角边分别是 1、2、3
  的等腰直角三角形，再分别以三条边为边长向外作正方形，数一数三个正方形各有多少格，
  填进记录单。"巡视时对卡住的学生只提示一句："正方形占了几个整格？"
- **学生活动**：独立画图、数格子；同桌核对结果；填写记录单前三行（边长栏 1、2、3，
  面积栏 1、2、4；4、8、16；9、18、27…按实际所画图形填写）。
- **设计意图**：对应 T2。**先走等腰直角三角形，是因为斜边上的正方形顶点恰好落在格点上，
  可以直接数格子。** 这一步把"割补"这个操作障碍暂时排除，让学生的注意力集中在
  "两个小正方形的面积加起来等于大正方形的面积"这一件事上。
- **评价点**：对应 T2。检查记录单上每组数据是否都满足"两个小正方形格数之和 = 大正方形格数"；
  再追问一句："三组数据都是这样，能不能说所有直角三角形都这样？"——把学生推向环节三。

> 【设计说明】这是本课的第一个顺序决策：**先排除操作障碍，再聚焦思维障碍。**
> 如果一上来就画直角边 3、4 的三角形，学生会先卡在"斜边正方形面积数不出来"上，
> 注意力被操作占满，反而看不到规律。规律探究课的通用顺序是：最简单的特例 → 一般情况 → 归纳。
> 注意记录单把"边长"和"面积"并排放在同一行，这是为环节四的抽象做准备。

### 环节三：一般情况探究——数格子与割补（13 分钟）

- **教师活动**：发下预印的"直角边为 3、4 的直角三角形三边正方形图"。先不给方法，
  提问："以斜边为边的这个正方形，格子数不满，面积怎么求？"收集学生的办法，
  请一位学生上台用磁性贴片示范割补（补成大正方形后减去 4 个直角三角形，
  或分割成 4 个直角三角形加 1 个小正方形）。示范后要求各组用两种方法各算一次。
  巡视时重点帮助仍在卡壳的组，提示语控制在"能不能把它补成一个规则图形"。
- **学生活动**：小组讨论求面积的思路；至少一组上台示范；各组独立用"补"和"割"
  两种方法各算一次并填表；组间核对结果（都应为 25）。
- **设计意图**：对应 T2 与 T3。这里是本课的难点所在，采用"**一组示范 + 各组仿做**"的方式，
  把空间操作的障碍拆成"看一遍"和"做一遍"两步。要求两种方法都算，
  是为了让学生体会"结果与算法无关"——这对结论的可信度很重要，
  也为下一课时的证明做铺垫。
- **评价点**：对应 T2。巡视时重点看三件事：①各组能否说出"补成大正方形再减去
  4 个直角三角形"的思路；②两种方法算出的面积是否一致（都是 25）；
  ③记录单上是否把 3、4、5 与 9、16、25 写在同一行。

> 【设计说明】"先收集办法、再请学生示范、最后各组仿做"这三步不能省。
> 如果教师直接演示割补，学生就只是在模仿一个技巧；先让学生自己想，
> 哪怕想不出来，也已经产生了"需要想办法"的紧张感，这时候再看示范才有收获。
> 注意教师巡视时的提示语被限制在"能不能补成规则图形"这一句——
> 提示语写具体是教案成熟的标志，它决定了教师不会忍不住把答案说出来。

### 环节四：归纳与表述——从面积到边长（6 分钟）

- **教师活动**：把三行数据投在屏幕上，提问："9、16、25 这三个数，和 3、4、5 有什么关系？"
  在学生说出 $9 = 3^2$ 之后追问："为什么正方形的面积正好等于边长的平方？"
  再问："你能把刚才的发现用一句话说清楚吗？"把学生的表述写在黑板上，逐字修改
  （重点抠"直角""斜边"两个词），最后给出规范表述与符号语言。
  最后问："如果 ∠C 不是直角，$a^2 + b^2 = c^2$ 还成立吗？"
- **学生活动**：观察数据找关系；用自己的话说出结论；对照规范表述找出自己表述的不足
  （常见：漏掉"直角"、把"斜边"说成"最长边"）；把符号语言记在笔记本上。
- **设计意图**：对应 T1。这是从"面积关系"抽象到"边长关系"的关键一跃，也是本课的
  第二个难点。记录单里"面积"和"边长平方"是同一个数，学生亲眼看到这一点，
  抽象就不再是凭空的。让学生**先自己表述、再对照规范表述**，
  是为了让"漏掉直角条件"这类问题自己暴露出来，比教师提前强调更有效。
- **评价点**：对应 T1。请 2 名学生复述定理内容；检查笔记本上是否写出了符号语言；
  用最后一个问题初步检验 T3 的判断力（学生应能说出"不成立，必须是直角三角形"）。

> 【设计说明】注意"追问为什么面积等于边长的平方"这一步。学生往往会跳过它，
> 因为对正方形来说这太"显然"了；但正是这一步把"面积"和"平方"两个概念连了起来，
> 不讲透，后面的抽象就是背下来的。**越是教师觉得"这还用问"的地方，越要问。**

### 环节五：验证与初步应用（8 分钟）

- **教师活动**：给出两个任务。
  任务一（验证）：在网格纸上画直角边为 2、5 的直角三角形，量出斜边长，
  比较 $2^2 + 5^2$ 与斜边长的平方。
  任务二（应用）：① 已知两直角边为 6、8，求斜边；② 已知斜边为 13、一条直角边为 5，
  求另一条直角边。巡视时重点看第二题是否有学生用减法时出错、是否有学生把 $c^2$ 当成 $c$。
- **学生活动**：任务一动手画图、测量、计算并记录；任务二独立完成，完成后同桌互查。
- **设计意图**：对应 T1、T2。任务一用"测量 + 计算"做一次经验验证，让学生体会
  "猜想需要检验"；同时测量必然有误差，这为下一课时的逆定理和严格证明留下伏笔。
  任务二检验知识能否应用，其中第②题是"已知斜边求直角边"，比第①题多一层变形。
- **评价点**：对应 T1。达标标准：任务二两题全对不少于 35 人。巡视时关注错误的类型——
  若出错集中在第②题，下课前用 1 分钟集体纠正；若出现把 $c^2$ 当 $c$ 的错误，
  在板书易错处现场标出。

> 【设计说明】评价点写了具体的达标标准（"不少于 35 人"）和错误类型的应对方案。
> 这是"可落地细节"的典型：不只是写"教师巡视指导"，而是写清**看什么、什么算达标、
> 发现问题怎么处理**。有经验的教师写教案时脑子里就在跑这些判断。

### 环节六：小结与作业布置（3 分钟）

- **教师活动**：提问三个问题——"这节课我们发现了什么？""我们是怎么发现的？"
  "发现的过程里，哪一步最难？"把学生的回答整理成板书上的探究链条：
  观察特例 → 数格子 → 割补求面积 → 归纳边长关系 → 检验。然后布置作业。
- **学生活动**：回答三个问题；同桌互说一遍勾股定理的内容与符号语言。
- **设计意图**：对应 T3。小结不是复述定理，而是回顾**研究方法**。
  让学生说出"哪一步最难"，是让他们把困难显性化，这对下一课时的证明有直接的迁移价值。
- **评价点**：对应 T3。听学生能否说出"割补求面积"这一步最难；能否说出研究是从特例开始的。

> 【设计说明】小结的三个问题分别对应"结论、方法、困难"。第三问是很多教案会漏掉的，
> 但它恰恰是学生元认知的入口。**小结让学生说，不是教师复述**——这是判断小结环节
> 是否有效的最简单标准。

## 板书设计

```
┌──────────────────────────────────────────────────────────────┐
│                 17.1 勾股定理（第 1 课时）                    │
├──────────────────────────────┬───────────────────────────────┤
│  主问题：                      │  探究路径                      │
│  直角三角形的三边之间          │  特例（等腰）→ 数格子          │
│  有什么数量关系？              │        ↓                      │
│                              │  一般情况 → 割补求面积         │
│  面积关系：S₁ + S₂ = S₃        │        ↓                      │
│        ↓  （面积 = 边长的平方） │  归纳 → 检验                   │
│  边长关系：a² + b² = c²        │                               │
│  （∠C = 90°，c 为斜边）        │                               │
├──────────────────────────────┴───────────────────────────────┤
│  易错：① 必须是直角三角形                                     │
│        ② c 一定是斜边，不能随便代入                            │
│        ③ 是"平方和"，不是"和的平方"                           │
└──────────────────────────────────────────────────────────────┘
```

> 【设计说明】板书左栏是**知识的结构**（面积关系 → 边长关系，用箭头表示推导方向），
> 右栏是**方法的结构**（探究路径），下栏是易错点。三块各有分工，
> 学生抬头一看就知道这节课学到了什么、是怎么得到的、容易错在哪。
> 如果板书只是"一、定理 二、例题 三、练习"，学生只能抄标题，看不到结构。

## 作业设计

- **基础题（对应 T1，全体必做）**：课本第 24 页练习第 1、2 题。
- **提升题（对应 T2，大部分学生完成）**：在方格纸上画一个直角边为 1、3 的直角三角形，
  用两种割补方法求出斜边上方正方形的面积，写出计算过程。
- **拓展题（对应 T3，选做）**：查阅"勾三股四弦五"的来历，写一段 100 字左右的说明：
  古人是怎么发现这个关系的？你觉得他们可能用了什么方法？

> 【设计说明】三层作业分别指向三条目标，且层次递进：基础题练应用，
> 提升题重做一遍"割补"这个难点（但换了数据），拓展题把方法迁移到数学史情境中。
> 每层都标注了对应的目标编号——**作业和目标对不上，说明作业是随便找的。**

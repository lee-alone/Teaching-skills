# Writing Humanizer (Professional & Academic Edition)

> 专注于**技术文章、教学指南、深度评论与严肃学术论文**的去 AI 味、结构去模板化与专业编辑工具。

---

## 💡 为什么需要这个项目？

大语言模型（LLM）在生成非虚构与学术文本时存在显著的系统性结构偏见：
1. **RLHF 长度与充水偏见**：模型倾向于堆砌“需要明确的是”、“值得一提的是”等无营养**元话语（Metadiscourse）**，并在结尾强行进行“开启了数字化全新范式”等**假大空升华**；
2. **论证均质八股化**：段落结构高度对称，机械循环“观点 $\rightarrow$ 阐述 $\rightarrow$ 总结”，滥用过渡词掩盖论证深度的匮乏；
3. **动词弱化与名物化堆叠**：频繁使用“进行优化”、“实现提升”等弱动词空转；
4. **深度 AI 痕迹**：重要性膨胀、系词回避、三板斧强迫症、公式化挑战段与破折号口癖；
5. **计算文体学失衡**：句子长度过于均一（低突发性）、缺乏人类专家写作特有的节奏呼吸与审慎限定。

同时，市面上常见的去 AI 工具往往简单粗暴地将文本往**口语化、俚语化、断句碎化**方向修改。这种做法不仅严重破坏了严肃学术与技术文章的专业语体，更是违背了学术规范。

本项目立足于学术研究与真实专业写作规律，坚持：**去 AI 味靠打破模板化句式与结构重塑，绝不靠降低语体和口语化凑数。保持严肃书面语体是不可妥协的硬底线。本工具旨在提升真实写作质量，明确不以规避或对抗检测器为目的，不承诺特定检测分数。**

## 🎯 核心原则

- **信息守恒（零幻觉、零篡改）**：严禁凭空编造未经说明的技术细节、实验数据或虚构参考文献；严禁删改技术边界条件。
- **专业实体绝对保护（Protected Spans）**：代码块、CLI 命令、配置参数、文件路径、数学公式、LaTeX、统计显著性指标（P值）及文献引用编号原样保留。
- **保持专业书面语体（硬底线）**：严禁加入网络热词、大白话、情绪词或泛滥的破折号。语体规范始终优先于字面修改指标。
- **机制透彻优于空洞口号**：用参数解析、因果推理和具体边界替代空泛形容词。
- **低耦合与单一职责**：所有规则、体裁、原理、替换库与脚本完全模块化，各司其职，按需加载。

## 🚀 四大使用模式

### 1. 普通改稿（默认模式）
适合技术博客、系统架构设计、教程科普与深度随笔的去味与结构优化：
```text
请对这篇文章进行去 AI 味改稿，重点清除元话语、动词名词化和空泛总结。
保留所有代码块与参数原意，篇幅控制在 90%–110%。
```

### 2. 学术论文正向润色模式
适合毕业设计、期刊论文、学术综述的规范化润色与结构优化：
```text
请对本篇论文的引言和讨论段落进行正向学术润色。
执行三轮编辑协议，保持严肃学术语体，绝对保护参考文献引用编号与实验数据，严禁口语化。
```

### 3. 严格白名单清理
适合正式技术规范、合规文档或必须字字保真的场景（仅按明确规则修改，未命中者逐字保留）：
```text
请按严格白名单模式清理本文，不改动未命中的句子和段落结构。
```

### 4. 自动化检测与诊断模式
通过内置 Python 脚本扫描 10 核心维度特征（含突发性 CV、受保护片段隔离、口语化预警与破折号超标检测）：
```bash
python scripts/aigc_scan.py your_paper.txt --threshold 0.5
```
或直接在对话中要求：
```text
请检测这篇文章中的 AI 痕迹与结构问题，输出诊断报告与最小修改建议。
```

## 🛠️ 自动化扫描器功能一览

内置 `scripts/aigc_scan.py` 原生无第三方重型依赖，扫描 10 个核心维度：

| 维度 | 对应检测机制 / 目的 | 风险阈值与处理 |
|---|---|---|
| **[1] 模板句式与翻案腔** | 知网语义指纹、GPT 常见套路 | 命中 > 3 处提示偏高，需确定性替换 |
| **[2] 被动语态比例** | 句式多样性，Turnitin 特征 | 非方法部分句均 > 0.4 且句子数 ≥ 5 建议改主动 |
| **[3] 突发性（CV）** | GPTZero 核心算法，检测句长方差 | 变异系数 CV < 0.35 预警句子过于均匀 |
| **[4] 段落对称性** | 格式规整度校验 | 连续 3 段以上长度偏差 < 20% 预警 |
| **[5] 嵌套编号模式** | 统计特征检测 | 频繁编号提示打破八股 |
| **[6] 冒号并列结构** | 逻辑断层与结构刻板检测 | 频繁并列提示自然叙述 |
| **[7] 标点规律性** | 万方 BERT 语义与逗号密度 | 句均逗号 > 2.5 预警逗号过密 |
| **[8] 口语化/网络热词** | **降重过度门禁（守学术/专业语体）** | **命中任意 1 处即高风险，直接判不合格** |
| **[9] 破折号密度** | **降重过度门禁（控制大模型跳跃口癖）** | **每段破折号超过 1 个即预警** |
| **[10] 模型退化与自指泄漏** | **死循环复读、拒答语与 AI 自指** | **发现自指或死循环复读即严重阻断** |

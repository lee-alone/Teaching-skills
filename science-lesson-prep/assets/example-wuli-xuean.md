# 匀变速直线运动的位移与时间的关系（导学示范）

## 学习目标

1. 能说出 $v-t$ 图象与时间轴所围的面积表示位移，会用面积法求位移。
2. 能推导位移公式 $x = v_0 t + \frac{1}{2}at^2$，并说明各物理量的含义。
3. 会用公式解决刹车、追及一类实际问题，解题时先判断运动是否仍在继续。

## 知识回顾

- 匀变速直线运动的速度公式：$v = v_0 + at$
- 加速度的定义式：$a = \frac{\Delta v}{\Delta t}$
- $v-t$ 图象的斜率表示加速度，斜率绝对值越大，速度变化越快。

## 探究一　用图象求位移

先看匀速直线运动：$v-t$ 图线与时间轴围成的矩形面积 $S = vt$，
恰好等于位移 $x$。

那么匀变速直线运动的 $v-t$ 图线是一条倾斜直线，它与时间轴围成的
梯形面积，是否也表示位移？

由图读出：初速度 $v_0 = 2\ \text{m/s}$，$t = 4\ \text{s}$ 时速度 $v = 10\ \text{m/s}$。

梯形面积 $x = \frac{v_0 + v}{2} \cdot t = \frac{2 + 10}{2} \times 4 = 24\ \text{m}$。

结论：匀变速直线运动的 $v-t$ 图线与时间轴围成的面积，数值上等于位移。

## 探究二　推导位移公式

把 $v = v_0 + at$ 代入梯形面积表达式：

$$x = \frac{v_0 + (v_0 + at)}{2} \cdot t$$

整理得到匀变速直线运动的位移公式：

$$x = v_0 t + \frac{1}{2}at^2$$

## 例题演练

例　汽车以 $v_0 = 20\ \text{m/s}$ 的速度行驶，刹车后做匀减速直线运动，
加速度大小 $a = 5\ \text{m/s}^2$。求刹车后 $3\ \text{s}$ 内汽车的位移。

解：先判断汽车停止所需的时间。

$$t_0 = \frac{v_0}{a} = \frac{20}{5} = 4\ \text{s}$$

因为 $3\ \text{s} < 4\ \text{s}$，汽车在 $3\ \text{s}$ 内仍在运动，可以直接用位移公式：

$$x = v_0 t - \frac{1}{2}at^2 = 20 \times 3 - \frac{1}{2} \times 5 \times 3^2 = 60 - 22.5 = 37.5\ \text{m}$$

注意：若所求时间超过刹车时间，必须先算出汽车何时停止，再代入公式，
不能直接把时间代进去。

::: blank 4

## 当堂检测

1. 物体做初速度为零的匀加速直线运动，$a = 2\ \text{m/s}^2$，求 $5\ \text{s}$ 内的位移。
2. 某质点运动的 $v-t$ 图线与时间轴围成的面积为 $18\ \text{m}$，已知初速度为
   $2\ \text{m/s}$，运动时间为 $6\ \text{s}$，求末速度。
3. 判断：匀减速直线运动中，位移一定随时间增大而减小。（　　）

## 课堂小结

| 内容 | 表达式 | 适用条件 |
| --- | --- | --- |
| 速度公式 | $v = v_0 + at$ | 匀变速直线运动 |
| 位移公式 | $x = v_0 t + \frac{1}{2}at^2$ | 匀变速直线运动 |
| 速度位移关系 | $v^2 - v_0^2 = 2ax$ | 不涉及时间时优先使用 |

> 提示：解题时先规定正方向，再确定各量的正负号，最后选择合适公式。

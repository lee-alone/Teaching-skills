# 词句替换表与禁词负面清单（Replacement Tables & Banned Words）

> 供改稿与查重降重时按需查阅。
> 严禁机械化一刀切替换，每处改动应根据具体语境选择最自然的表达方式。

---

## 一、 词级推荐替换表

### 1. 模板连接词
- **此外** $\rightarrow$ 另一方面 / 另一组数据则显示 / 直接删除 / 从另一维度看
- **与此同时** $\rightarrow$ 同时 / 另一方面 / 结合前文来看
- **综上所述** $\rightarrow$ 直接删除 / 概括具体结论 / 综合来看
- **需要指出的是** $\rightarrow$ 值得注意的是 / 需说明的是 / 直接删除
- **研究发现 / 表明** $\rightarrow$ 实验表明 / 数据呈现 / 结果显示 / 测试证实
- **分析认为** $\rightarrow$ 推测 / 可能的原因在于 / 据此判断 / 这一现象提示
- **具体而言** $\rightarrow$ 从实测来看 / 细化分析 / 拆开来看

### 2. “XX了”高危特征句式
- **揭示了** $\rightarrow$ 指向了 / 表明 / 体现出
- **探讨了** $\rightarrow$ 考察了 / 分析了 / 梳理了
- **验证了** $\rightarrow$ 确认了 / 证明了 / 实测结果支持
- **构建了** $\rightarrow$ 建立了 / 搭建了 / 实现了
- **展示了** $\rightarrow$ 呈现了 / 反映了 / 表现出
- **导致了** $\rightarrow$ 造成了 / 引发了 / 使得

### 3. 动词系统性替换
- **显著** $\rightarrow$ 明显 / 大幅 / 可观地
- **增加** $\rightarrow$ 上升 / 提高 / 攀升 / 增长
- **降低** $\rightarrow$ 下降 / 减小 / 削弱 / 回落
- **提升** $\rightarrow$ 增强 / 改善 / 优化
- **影响** $\rightarrow$ 改变 / 调控 / 左右
- **促进** $\rightarrow$ 推动 / 驱动 / 有利于
- **抑制** $\rightarrow$ 限制 / 阻碍 / 约束
- **归因于** $\rightarrow$ 源于 / 主要在于 / 原因之一是

## 三、 英文 AI 高危套话与禁用词清单（English AI Slop & Banned Words）

用于英文技术与学术写作改写时重点剔除：

### 1. 禁用空洞动词与名词（Banned Words）
```text
delve, foster, leverage, utilize, facilitate, empower, streamline,
robust, cutting-edge, paradigm shift, game changer, tapestry, realm,
beacon, multifaceted, meticulous, intricate, paramount, transformative,
elevate, embark, supercharge, harness, ever-evolving, testament.
```

### 2. 常见空转副词与短语（Often-empty fillers）
- **空转副词**（非确凿强调时一律剔除）：`just`, `literally`, `truly`, `fundamentally`, `crucially`, `inherently`, `inevitably`。
- **空转短语**（删去后直入主题）：`it's worth noting`, `it's important to note`, `at the end of the day`, `in today's world`, `in the age of`, `the reality is`, `in terms of`, `with regard to`, `in order to`, `going forward`。

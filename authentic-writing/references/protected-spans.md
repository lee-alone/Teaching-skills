# 受保护片段与实体保真契约（Protected Spans）

> 核心契约：**去 AI 味与叙事重塑绝不能以牺牲技术与事实真确性为代价。所有受保护片段必须 100% 保真，严禁在润色或改写中篡改、虚构或删减。**

---

## 一、 必须 100% 绝对保真的内容清单

在进行改稿、叙事重塑或去 AI 处理时，以下元素属于**最高保护区**：

1. **代码与工程资产**：
   - 多行代码块（```...```）、行内代码（`...`）；
   - Linux CLI 终端命令、Shell 脚本片段；
   - 配置文件参数、环境变量、YAML/JSON 键值对、文件绝对/相对路径、端口号。
2. **数学与统计表达**：
   - LaTeX 块级公式（`$$...$$`）与行内公式（`$...$`）；
   - 算法伪代码与变量下标；
   - 统计显著性指标（如 $p < 0.01$、F1-score、置信区间、标准差、误差棒范围）。
3. **数据实体与边界**：
   - 实验测量值、测试集名称、并发 QPS、延迟 ms、内存占用数值；
   - 明确的时间节点、年份、版本号；
   - 原文明确指出的适用边界、物理约束条件。
4. **学术与规范引用**：
   - 文献引用编号（如 `[1]`, `[12-15]`）及其上下文对应关系；
   - 图表编号（如 `图 3`, `表 2`）及图题标注；
   - 国际标准编号（如 RFC 7540、ISO/IEC 27001）。

---

## 二、 语义与事实守恒核对标准

在输出成稿前，执行暗默比对：
- **零新增（Zero Hallucination）**：严禁凭空捏造原文未提供的数据、参数、API 或虚构参考文献；
- **零丢失（Zero Omission）**：严禁为了行文“流畅”擅自删减原文的否定判断（如“不支持分布式事务”）或限制前提（如“仅在只读副本生效”）；
- **术语一致性（Global Terminology Lock）**：
  - 核心术语一经确立，全篇必须自始至终保持完全一致，严禁为了避免字面重复而强行同义替换。

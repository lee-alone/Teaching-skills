# 优秀教案的结构与思考路径

## 一、底层逻辑：倒推 + 闭环

绝大多数低质量教案是"顺写"出来的——从"这节课我要讲什么"开始，想到哪写到哪，
最后补一段目标。这样写出来的东西，目标是从过程里"总结"出来的，不是从课标
"推"出来的，所以必然空泛，也必然和过程对不上。

优秀教案是"倒推"出来的：

```
课标要求 ──► 这节课的素养落点 ──► 可观测的目标 ──► 重难点 ──► 活动/问题链 ──► 评价
     ▲                                                                        │
     └──────────────────── 闭环检查：每个目标都有落点和证据 ◄────────────────┘
```

**写作时的执行顺序必须是：第 1 步 → 第 6 步，不许跳步，不许从活动写起。**
（教案最终呈现的板块顺序可以另排，但思考顺序不能变。）

---

## 二、六个思考步骤（展开版）

### 步骤 1：定位课标与素养落点

要回答的三个问题：

1. 这节课对应课标的哪条内容要求？（概括即可，不要编造原文和引号）
2. 这节课最能在哪 1–2 个素养条目上使劲？
3. 使劲的方式是什么？（是"通过动手操作发展几何直观"，还是"通过史料辨析
   发展史料实证"——要写出具体路径）

**不合格**：通过本节课培养学生的科学思维和探究能力。
**合格**：通过让学生自己设计"如何判断浮力大小与哪些因素有关"的探究方案，
在控制变量的取舍中发展科学探究素养。

### 步骤 2：写可观测的目标

详见 `objective-writing.md`。核心：**目标写完之后，应该能据此出一份小测。**

### 步骤 3：由目标倒推重难点

| | 怎么定 | 必须写到什么程度 |
| --- | --- | --- |
| **重点** | 目标里占用时间最多、居于核心的那一条对应的知识或方法 | 写清"是什么"，一句话 |
| **难点** | 学生达成目标时最可能卡住的地方 | 写清"卡在哪 + 为什么卡 + 怎么破"三件事 |

难点的三种典型来源，写的时候对号入座：

- **前概念干扰**：学生已有的生活经验或旧知识是错的/不完整的
  （例：认为"重的物体下落快"；认为"分数就是分子比分母小"）
- **抽象度跃升**：从具体到抽象、从静态到动态、从特殊到一般的一跃
  （例：从"算出一个具体的值"到"讨论一个对应关系"）
- **操作/表达障碍**：想得到但做不出、说不出、写不出
  （例：知道该用反证法但写不出规范的推理格式）

### 步骤 4：设计主线

一节好课有一条主线。没有主线的课，学生记住的是一堆碎片。

**问题链驱动**的写法：

```
主问题：______（整节课要回答的那个大问题，一句话）
  ├─ 子问题 1：______ → 预期学生回答：______ → 追问方向：______
  ├─ 子问题 2：______ → 预期学生回答：______ → 追问方向：______
  ├─ 子问题 3：______ → 预期学生回答：______ → 追问方向：______
  └─ 回到主问题：学生用自己的话回答 ______
```

问题链的质量标准：

- 主问题要有"张力"——答案不是书上抄一句就有的，需要这节课学完才能回答。
- 子问题之间要有**递进**，不是并列。检验办法：能不能把子问题的顺序打乱？
  能打乱，说明是并列的碎片，不是链条。
- 每个子问题都要写"预期学生回答"。不写这个，课堂就会变成"教师问—学生沉默—教师自己答"。
- 每个子问题都要写"追问方向"，即学生答错或答偏时怎么接。

**活动主线驱动**的写法：把一节课做成"完成一件事"的过程
（设计一个方案、解决一个真实问题、做一次完整的实验探究、办一次展评）。
每个活动是任务的一个环节，环节之间是"做事的先后"，不是"知识的罗列"。

### 步骤 5：逐环节落实四要素

每个环节必须有：

- **教师活动**：教师做什么、说什么、问什么、板书什么、什么时候介入
- **学生活动**：学生做什么——是听、是想、是动手、是讨论、是写、是展示
- **设计意图**：这一环节为什么存在，对应哪条目标，突破哪个难点
- **评价点**：怎么知道学生达成了——看什么、听什么、查什么

**"设计意图"和"评价点"是最常被漏掉、也最能区分教案水平的两个字段。**
没有"设计意图"，环节就是无来由的；没有"评价点"，课堂就无法判断有没有教会。

### 步骤 6：闭环检查

填「目标—活动—评价」三栏对照表（格式见 SKILL.md 第 6 步）。
再对照 `quality-checklist.md` 逐条过。

## 三、各板块的写作要求

### 1. 课题信息

必备：学科、年级、教材版本与册次、课题、课时（第几课时／共几课时）、课型、授课时间。
用表格或 YAML 头都行，但要齐。

### 2. 教材分析

写三句话：这节课在**本单元**中的位置、在**本册/本学段**中的地位、
与本课前后的**逻辑关系**（承什么、启什么）。

**不合格**：本节内容是初中数学的重要内容，为后续学习打下基础。
**合格**：本节是在学生已学"一元一次方程"之后的第二类方程模型，其解法中
"配方"的思想直接服务于后续二次函数的顶点式研究，因此本节课要留出时间
让学生体会"把一般式化为顶点式"的价值，而不只是熟练求根。

### 3. 学情分析

**这是最容易写成空话的板块。** 必须写具体：

| 要写什么 | 不合格 | 合格 |
| --- | --- | --- |
| 已有基础 | 学生基础较好 | 学生已能熟练进行分式化简与因式分解，上节课的课前测显示 38/45 人能在 3 分钟内完成十字相乘 |
| 前概念／迷思 | 学生对概念理解不深 | 约 2/3 的学生会把"$\sqrt{4}$ 等于 ±2"当作正确，因为在解方程时习惯了"开方要带正负号" |
| 学习障碍 | 学生抽象思维较弱 | 学生能算出具体的函数值，但难以理解"对应关系本身"是研究对象，需要借助表格与图象先建立直观 |
| 差异 | 学生水平参差不齐 | 约 8 名学生已能自主完成变式，需准备拓展题；约 5 名学生计算不过关，需提供步骤提示卡 |

数据可以来自课前测、作业统计、经验判断——但**要写成可检验的说法**，
不要写成"学生基础较好/较差"这类没有信息量的话。

### 4. 教学目标

见 `objective-writing.md`。编号 T1、T2、T3…

### 5. 教学重点与难点

见步骤 3。难点要写"卡在哪 + 为什么卡 + 怎么破"。

### 6. 教学思路（设计思路与主线架构）

**这是中学（初高中）优秀教案的灵魂所在，绝不可省略。**
中学的课堂思维深度要求高，没有顶层设计，教学过程就会变成零散的步骤拼盘。
教学思路必须在进入微观环节之前，把整节课的**宏观认知骨架与思维进阶路线**彻底交代清楚。

包含三部分：

1. **整体教学构想（核心灵魂）**：
   用一句话或一段话阐明本课的核心设计逻辑：基于什么真实情境，依托什么思维主线，经历怎样的认知跃升，达成哪些核心素养。
2. **主线架构图（问题链／任务链）**：
   用结构图或递进树（ASCII 代码块）直观呈现：
   - 1 个核心主问题（上位统领，具有张力）
   - 3–4 个层层递进的子问题（标注驱动的思维动作及目标指向 T1/T2/T3）
   - 总结升华闭环
3. **难点攻坚路线图（认知障碍破除路径）**：
   清晰写出思维转化链条：
   `学生前概念/思维断点 ──► 认知冲突/实验/变式支架 ──► 思维转折 ──► 新知建构与通法提炼`

### 7. 教学准备

教师准备（教具、课件、学具、分组安排、预印材料）与学生准备（预习任务、材料）。
写具体数量与形式：不是"准备多媒体课件"，而是"准备 12 组（每组 2 人）的
长方形纸片、剪刀、量角器；预印探究记录单 45 份"。

### 8. 教学过程

分环节写，格式固定（见 SKILL.md 第 5 步）。各环节用时之和 = 课时长度 − 机动。

### 9. 目标—活动—评价对照表

格式固定。**任何一格填不出来，说明设计有漏洞。**

### 10. 板书设计

板书是**知识结构的可视化**，不是标题的罗列。

合格板书要能看出：核心概念居中/居上、各要素之间的箭头或层级关系、
易错点的标注、以及本课结论的位置。

写法：用 Markdown 代码块画出板面布局，例如

```
┌────────────────────────────────────────────┐
│              一元二次方程的解法             │
├──────────────────┬─────────────────────────┤
│  直接开平方法     │  配方法                  │
│  x² = p (p≥0)    │  → (x+m)² = n            │
│  ↓ 因式分解       │  ↓ 公式法                │
│  (x-a)(x-b)=0    │  x = (−b±√(b²−4ac))/2a   │
├──────────────────┴─────────────────────────┤
│  易错：① 开方漏负根 ② 判别式先算           │
└────────────────────────────────────────────┘
```

### 11. 作业设计

分三层，且每层要指回目标：

| 层次 | 指向 | 说明 |
| --- | --- | --- |
| 基础题 | 指向 T1 | 全体必做，检验最基本的知识技能 |
| 提升题 | 指向 T2 | 大部分学生完成，需要一点迁移 |
| 拓展题 | 指向 T3 | 选做，给学有余力的学生 |

每道作业后标注对应目标编号，例如「（对应 T2）」。

### 12. 教学反思

教案阶段**留空并写明"课后填写"**，不要提前编造。可以留几个待反思的问题作提示，
例如"环节三的小组讨论是否给了足够时间？"。

## 四、时间分配的一般规律

一节课 40 或 45 分钟，供参考的分配：

| 环节 | 占比 | 说明 |
| --- | --- | --- |
| 情境导入／复习铺垫 | 10%–15% | 不超过 6 分钟，不要变成"上一节课的补课" |
| 新知探究／主体活动 | 50%–60% | 学生活动时间必须占这一段的一半以上 |
| 巩固练习／应用 | 15%–20% | 当堂练，当堂反馈 |
| 小结与作业 | 8%–10% | 小结让学生说，不是教师复述 |
| 机动 | 8%–12% | 3–5 分钟，用来应对生成性问题 |

**学生活动总时长应不低于课堂总时长的 50%。** 低于这个数，说明这节课还是"讲"出来的。

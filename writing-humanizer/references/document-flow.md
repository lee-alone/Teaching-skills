# 篇章结构与教学节奏规范

基于人类专业论述结构与 LLM 机械对称性的对比，本文件指导非虚构文章（技术文章、教学指南、知识科普、深度评论）的篇章级诊断与结构调整。

---

## 一、 核心病征诊断

### 1. 八股式段落循环（Symmetrical Sections）
- **现象**：每一节或每个要点，都无差别地使用“一段概括 + 一段解释 + 一句意义总结”。
- **危害**：抹平了技术重点，核心机制与次要配置权重相同，读者极易认知疲劳。
- **改法**：
  - 核心原理/踩坑点：展开机制细节，提供上下文与权衡分析。
  - 次要/常规操作：单刀直入，合并或表格化，快速交代。

### 2. 机械路标词轰炸（Signpost Overload）
- **现象**：全文高频出现“首先、其次、再者、此外、最后、综上所述”。
- **危害**：用低幼化的序数词强行拼接，掩盖了逻辑内部的因果递进缺失。
- **改法**：
  - 优先依靠句际语义推进（因果、转折、递进、时序）自然连接；
  - 仅在真正的多步骤操作流程中保留清晰步骤编号。

### 3. 操作流水账（The Step-by-Step Void）
- **现象**：教学文章只机械陈列“第1步运行X，第2步打开Y，第3步修改Z”，缺乏对“为什么选这个方案”、“可能出现什么报错”、“参数背后的含义”的交代。
- **危害**：类似监控摄像头录像，没有体现作者作为专业实践者的经验与判断。
- **改法**：
  - 在关键步骤补充真实技术上下文（“注意此参数若超过 100 会触发限流”）；
  - 去除没有信息增量的过渡动作（“接下来，我们需要点击进入下一个界面并等待...” $\rightarrow$ 直接指出目标路径）。

### 4. 结尾假大空升华（Superficial Elevation）
- **现象**：文章结尾必然出现“正如我们所见，X技术不仅改变了当下，更为未来的AI浪潮开启了全新的范式，让我们拭目以待”。
- **危害**：典型的 RLHF 讨好型充水，严重损害技术文章的专业严谨性。
- **改法**：
  - **直接截断**：若前文技术方案已完整交付，直接结束，无需多余总结。
  - **收束于真实边界**：若需结尾，总结为“局限性”、“适用场景清单”或“下一步延伸阅读”，拒绝虚空抒情。

## 二、 篇章优化执行步骤

1. **宏观扫读**：通读全文，识别是否存在“段落长度完全一致”、“每个小标题后结构完全相同”的现象。
2. **权重重分配**：
   - 找出全文的**核心价值增量**（独家实践、深层机制、关键避坑点）；
   - 压缩或合并**通用常识与空泛过渡**。
3. **路标词清理**：删掉段首生硬插入的“不仅如此”、“毫无疑问”、“显而易见”，让上下文陈述自然衔接。
4. **尾部脱水**：清除最后一段或各小节末尾的无意义展望套话。

# anti-ai-narrative

基于 OpenAI 文本检测研究与一线实证视角的深度去 AI 味与叙事重塑工具。

## 简介

本项目摒弃了传统的死板关键词过滤，通过模型自主认知启发式判断，根除：
- 均质化推进（均匀句长与段落）
- 微型总分总套娃（每段末尾假升华）
- 工整对称标题（四字排比+冒号）
- 万米高空宏大叙事（口号式行话空转）
- 黑格尔式假辩证（无成本既要又要）

适用于学术论文、技术架构复盘、商业分析、公文调研等各领域文章的深度去 AI 化与叙事重塑。

## 核心方法

1. **一线工作台测试（The Workbench Test）**：视角下沉至具体工单、报错、参数与阻力。
2. **概念剥离测试（The Friction Test）**：剔除跨行业无缝通用的空壳废话，注入专属摩擦力与妥协代价。
3. **反均质化测试（The Burstiness Test）**：长短句交错，断然删除段尾假升华，制造高突发度。

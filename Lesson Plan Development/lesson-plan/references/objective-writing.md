# 教学目标的写法

## 一、为什么"理解""掌握"不能用

"理解""掌握""了解""体会"这类词描述的是**学生头脑内部的状态**，
从外面看不见、测不到。写进目标里，等于没写——上课时无法判断达成了没有，
下课后无法检验教会了没有。

**判断标准很简单：读完这条目标，能不能据此出一道题或设计一个观察点？**
不能，就是空泛目标。

| 空泛目标 | 为什么不行 | 改法 |
| --- | --- | --- |
| 理解二次函数的概念 | "理解"看不见 | 能用自己的话说明 $y=ax^2+bx+c$ 中 $a \neq 0$ 的必要性，并能从三个具体情境中判断是否为二次函数 |
| 掌握勾股定理 | "掌握"测不到 | 已知直角三角形的任意两边，能正确求出第三边，正确率不低于 90% |
| 培养学生的合作能力 | 太笼统，一节课培养不出来 | 在小组测量活动中，能主动承担分工任务并向同伴说明自己的测量数据 |
| 体会数学的美 | 无法观测 | 能在教师给出的三组图形中，指出至少一处对称或简洁的表达并说明理由 |
| 了解作者的情感 | 无法观测 | 能找出文中两处直接抒情的句子，并结合写作背景说明作者情感的变化 |

## 二、目标公式

```
主语（学生） + 可观测的行为动词 + 条件/情境 + 标准/程度
```

- **主语**：一律是"学生"，行文中常省略，但动作的发出者不能是教师。
  （"引导学生……"是教师行为，不是目标。）
- **行为动词**：必须能看见学生"做"出来什么。
- **条件**：在什么情况下、借助什么工具、给出什么材料。
- **标准**：做到什么程度算达标——数量、时间、正确率、完整度、独立程度。

示例拆解：

> 在给出的一次函数图象中（条件），学生能**说出**（动词）
> 图象与两坐标轴交点的实际意义（内容），并**至少举出 2 个**（标准）
> 生活中符合该变化规律的例子。

## 三、可观测动词库

### 按认知层次排（由低到高）

| 层次 | 常用动词 |
| --- | --- |
| 识记 | 说出、写出、指出、列举、标出、默写、辨认、复述 |
| 理解 | 解释、说明、比较、分类、归纳、举例、用自己的话概括、判断并说明理由 |
| 应用 | 计算、求解、作图、测量、使用、操作、代入、按步骤完成 |
| 分析 | 分析、区分、找出……的原因、推断、拆解、找出错误并改正 |
| 评价 | 评价、评判、论证、质疑、判断……是否合理并说明依据、指出优缺点 |
| 创造 | 设计、提出、拟定、改编、建构、创作、制定方案、提出假设 |

### 分学科常用动词

| 学科 | 常用动词 |
| --- | --- |
| 语文 | 朗读、背诵、圈画、批注、概括、赏析、仿写、改写、辩论、撰写、比较不同版本的…… |
| 数学 | 计算、求解、作图、证明、验证、估算、建立模型、用符号表示、举出反例 |
| 英语 | 朗读、复述、role-play、根据关键词复述、用目标句型描述、判断正误并改正、写出……的提纲 |
| 物理／化学／生物 | 测量、操作、观察并记录、提出假设、设计实验、控制变量、绘制图象、分析数据、得出结论 |
| 政治／历史／地理 | 提取信息、比较、辨析、论述、绘制示意图、分析图表、说明成因、评价影响 |

## 四、三维目标的写法

### 第一维：知识与技能（指向"学会了什么"）

写具体的知识内容和技能操作，是三条目标里最容易写实的。

> **T1** 学生能写出二次函数的一般式与顶点式，并说出 $a$ 的符号与开口方向的关系，
> 在给出的 6 个函数式中判断正确的不少于 5 个。

### 第二维：过程与方法（指向"怎么学会的"）

**这一维最容易写成空话。** 不要写"通过观察、猜想、验证的过程培养探究能力"——
要写清楚学生在哪个具体的环节里、做什么具体的动作、发展什么具体的能力。

> **T2** 在探究"$a$ 的取值对图象的影响"时，学生能通过列表取值、描点作图、
> 小组比较三组图象，用自己的话归纳出 $a$ 与开口方向、开口大小的关系。

### 第三维：情感态度与素养（指向"成为什么样的人"）

**这一维最容易被写成放之四海皆准的口号。** 写法要求：**必须挂在一个具体的
学习活动上**，学生在这个活动里表现出什么行为，才算达成。

> **T3** 在小组比较图象的过程中，学生能主动用"当 $x$ 增大时……"这类数学语言
> 向同伴说明自己的判断，并接受同伴的质疑后修改结论。

## 五、目标的条数与配比

- **3–4 条为宜**。少于 3 条覆盖不全，多于 4 条一节课完不成，且必然有凑数的。
- 三维不必平均分配：新授课常见 1 条知识、1–2 条过程、1 条素养。
- **每条目标都必须编号**（T1、T2、T3…），编号在后面的对照表和作业设计里要用到。

## 六、按核心素养分写的情况

若本地区或学校要求目标按核心素养条目分写（例如数学写"通过……发展几何直观"），
**可观测的要求不变**，只是分组的依据变了。写法：

> **T2（推理能力）** 学生能根据已证的判定定理，独立写出一个完整的几何证明，
> 每一步注明依据，不出现"由题可知"这类无依据的跳步。

不要写成"发展推理能力"就结束——**素养是方向，目标必须落到行为上**。

## 七、自查：把目标翻译成小测

写完目标后，用 3 分钟做这件事：**给每条目标编一道能检测它的小题或一个观察点。**

- 编不出来 → 这条目标不可测，重写。
- 编出来但发现和另外一条目标考的是同一件事 → 两条目标重复了，合并。
- 编出来的题这节课根本没教 → 目标超出教学过程，删掉或补教学环节。

这一步是"目标空泛"最有效的解药，比反复读目标本身有用得多。
